# Практика

Telegram Mini App для обучения: разделы, статьи с картинками, видеоуроки и редактор контента. Техническое задание находится в [docs/SPEC.md](docs/SPEC.md).

## Локальный запуск

Требуется Node.js 22 или новее.

```sh
npm ci
npm run dev
```

Откройте http://localhost:3000. Без DATABASE_URL показывается демонстрационный каталог. Демо ничего не записывает и не заменяет ошибки реальной базы.

Для локальной SQLite скопируйте `.env.example` в `.env.local` и задайте `DATABASE_URL=file:local.db`. Затем:

```sh
npm run db:init
npm run db:seed
npm run dev
```

`db:init` создаёт таблицы, повторный запуск безопасен. `db:seed` добавляет демонстрационные материалы, не перезаписывая существующие. Для чистой библиотеки выполните только `db:init`. Файлы базы и секреты исключены из Git.

В браузере библиотека доступна без авторизации. Админка требует реального запуска через Telegram: обхода входа для разработки нет. Автоматические тесты используют отдельную SQLite и искусственные тестовые Telegram-подписи.

## Развёртывание на Vercel

1. В проекте mini-app проверьте подключение репозитория `imnotplastina/mini-app`, production-ветку `main` и корневую папку репозитория (Root Directory оставьте пустым). Файл `vercel.json` фиксирует Framework Preset `Next.js`, Install Command `npm ci`, Build Command `npm run build` и Output Directory `.next`, переопределяя старые настройки статического проекта. После добавления этого файла нужен новый deployment из обновлённого `main`.
2. Создайте удалённую базу libSQL/SQLite, например в Turso. Используйте libSQL-совместимый endpoint. Локальный `file:local.db` для Vercel не подходит: функции не имеют общего постоянного диска. Приложение отклоняет такой режим на Vercel. [Объяснение Vercel](https://vercel.com/kb/guide/is-sqlite-supported-in-vercel).
3. Добавьте переменные окружения из таблицы ниже. Доступ к базе нужен только серверу. Не используйте префикс `NEXT_PUBLIC_` для секретов.
4. Инициализируйте удалённую базу: в локальном `.env.local` временно укажите её URL и токен, выполните `npm run db:init`. При необходимости добавьте примеры командой `npm run db:seed`. После этого верните локальные настройки. Инициализация не запускается автоматически при сборке.
5. Для загрузки картинок создайте публичное хранилище Vercel Blob и подключите его к проекту. Без Blob можно использовать HTTPS-ссылки на изображения.
6. Выполните deployment и проверьте production URL без входа в аккаунт Vercel. При изменении переменных выполните Redeploy. Preview и Production должны использовать разные базы и секреты.
7. Откройте приложение из Telegram, перейдите в «Профиль», скопируйте подтверждённый Telegram ID в ADMIN_TELEGRAM_IDS и выполните Redeploy. В профиле появится кнопка управления материалами.

| Переменная | Значение |
| --- | --- |
| DATABASE_URL | Локально `file:local.db`; на Vercel `libsql://…` удалённой SQLite |
| DATABASE_AUTH_TOKEN | Токен удалённой libSQL; локальному файлу не нужен |
| TELEGRAM_BOT_TOKEN | Новый токен от BotFather; используется только сервером |
| SESSION_SECRET | Случайный секрет не менее 32 символов |
| ADMIN_TELEGRAM_IDS | Числовые ID администраторов через запятую |
| BLOB_READ_WRITE_TOKEN | Токен подключённого публичного Vercel Blob, нужен для загрузки изображений |

Сгенерировать секрет сессий можно локально:

```sh
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
```

Не публикуйте результат. Токен бота, уже переданный в переписке, нужно перевыпустить через `/revoke` в @BotFather до production-запуска. Он не включён в код или конфигурационные примеры.

## Если Vercel показывает 404 при статусе Ready

Если `/images/start.svg` открывается, а `/` и `/api/auth` отвечают платформенным `404 NOT_FOUND`, вероятна публикация только папки `public` с оставшимся от HTML-проекта пресетом. Наличие `Ready` означает завершение развёртывания, но не подтверждает правильную настройку Next.js.

Убедитесь, что `vercel.json` попал в `main`, и откройте новый deployment именно этого коммита. В Build Logs должны присутствовать сборка Next.js и маршруты `/`, `/api/auth`, `/lessons/[id]`. В настройках проекта Root Directory должен указывать на корень, где лежат `package.json` и `vercel.json`. Если после успешной сборки прямой URL нового deployment работает, а основной домен нет, проверьте назначение домена этому production-развёртыванию.

Для проверки главной страницы база и токен не требуются: без переменных приложение показывает демонстрационные материалы.

## Telegram

Владелец уже указал ссылку в настройках бота. После развёртывания проверьте, что Main Mini App и Menu Button в @BotFather открывают именно production HTTPS URL приложения. Адрес панели `vercel.com/.../mini-app` для этого не подходит.

Для кнопки меню используйте `/setmenubutton`, текст — «Обучение». Main Mini App настраивается в карточке бота в BotFather. Прямая ссылка после настройки имеет вид `https://t.me/USERNAME_БОТА?startapp`.

Webhook и постоянно запущенный процесс бота для этих способов открытия не нужны. Ответ на `/start`, рассылки и загрузка материалов через чат бота в эту версию не входят. [Документация Telegram](https://core.telegram.org/bots/webapps).

## Редактирование

Откройте «Профиль → Управление материалами». Сначала создайте раздел, затем урок. Материалы создаются черновиками. Для публикации выберите статус «Опубликован» и сохраните. Уроки чернового раздела не видны читателям. Снятие с публикации заменяет удаление.

Редактор поддерживает Markdown и предпросмотр. HTML и JavaScript из текста не исполняются. Изображение можно загрузить (JPEG, PNG, WebP, GIF до 4 МБ) или вставить по HTTPS-ссылке. Для видео укажите прямую ссылку на MP4; ссылки на страницы видеоплатформ не поддерживаются. Видео поступает напрямую из медиахранилища, без проксирования через Vercel Functions.

Одновременные изменения защищены номером версии: устаревшая запись получает конфликт, вместо того чтобы перезаписать чужие изменения. При конфликте скопируйте свой текст, закройте форму, обновите список и перенесите нужные правки в актуальную версию.

Демонстрационное видео с цветком: [MDN Interactive Examples](https://github.com/mdn/interactive-examples), CC0. Иллюстрации SVG созданы для проекта. Перед публичным запуском замените демонстрационный материал своим контентом. Рабочее название «Практика» находится в `app/layout.tsx`, `components/shell.tsx` и `components/catalog.tsx`.

## Проверка

```sh
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Браузерные тесты запускают отдельное приложение на порту 3100 и отдельную базу в `.artifacts`; не указывайте production-секреты в тестах. Проверяются поиск, фильтрация, навигация, мобильная ширина, ошибка видео, ограничения API, сохранение черновика и публикация через редактор. Unit-тесты проверяют HMAC, устаревшие/поддельные данные, видимость публикаций и конфликты SQLite.

После подключения production отдельно проверьте на реальных Telegram iOS и Android: запуск из кнопки, получение ID, вход администратора, загрузку картинок, воспроизведение/перемотку/полноэкранный режим видео, тёмную тему и кнопку «Назад». Локальные браузерные тесты не заменяют эти проверки.
